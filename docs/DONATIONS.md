# Donations (voluntary, optional)

Copyright (c) 2026 rickkyy. MIT — all functions are free for everyone.

- Donating is **voluntary and optional**. The same build, features, and
  fixes are available whether or not you donate.
- **No PayPal link is published yet.** This repo ships no active donate
  button, no placeholder link, no email, and no personal credentials.
- Monetization, if ever enabled, will be the same MIT code + an optional
  user-provided PayPal link. Nothing is paywalled.

## For the maintainer (how to add PayPal later)

1. Create a PayPal.Me / donate link in your own PayPal account
   (private, outside this repo).
2. Open `.github/FUNDING.yml` and replace the **commented** example line
   with your real link, e.g. uncomment and set:
   `custom: ["YOUR_PUBLIC_PAYPAL_DONATION_URL"]` with the real public URL.
   GitHub uses the `custom` key for PayPal; there is no `paypal` funding key.
   Keep it as the only active funding key unless you add others
   deliberately.
3. Mention the link in this file and in `README.md` in the same change.
4. Never commit emails, tokens, or private account data.

## For supporters (once a link exists)

- Use the link from `.github/FUNDING.yml` (the "Sponsor" button).
- Donations do not buy priority, features, or support — they only help
  cover hardware/time if the maintainer says so at the time.
