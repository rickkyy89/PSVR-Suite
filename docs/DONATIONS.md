- **PayPal:** rickkyy89@proton.me (published at the maintainer's

## For the maintainer (how to add PayPal later)

1. The PayPal donation address is published: rickkyy89@proton.me
   (mailto link in `.github/FUNDING.yml` under the `custom` key —
   GitHub has no `paypal` funding key). To change it, update the email
   in `FUNDING.yml`, this file, and `README.md` in the same change.
2. Never commit tokens, passwords, or private account data. The PayPal
   email above stays public only because the maintainer explicitly
   requested it.

## For supporters (once a link exists)

- Use the link from `.github/FUNDING.yml` (the "Sponsor" button).
- Donations do not buy priority, features, or support — they only help
  cover hardware/time if the maintainer says so at the time.
